# Business Diagrams — Визуальное моделирование бизнес-процессов

## О проекте
Учебный проект Школы 21 (2 месяца, индивидуально).  
Разработал комплекс диаграмм для анализа и документирования бизнес-процессов.

## Моя роль
- Проанализировал требования стейкхолдеров
- Спроектировал BPMN-диаграммы бизнес-процессов
- Создал UML-диаграммы (Use Case, Sequence, Activity)
- Разработал ER-диаграмму базы данных
- Подготовил документацию для разработчиков

## Выполненные задачи

### Задание 1: Анализ предметной области
- Изучил доменную область и бизнес-контекст
- Выявил ключевых стейкхолдеров и их потребности
- Определил границы системы

### Задание 2: BPMN-моделирование
- Спроектировал AS-IS процесс (как есть сейчас)
- Разработал TO-BE процесс (как должно быть)
- Выявил узкие места и точки улучшения

### Задание 3: UML Use Case диаграмма
- Идентифицировал акторов системы
- Описал основные use cases
- Определил отношения между вариантами использования

### Задание 4: Sequence Diagram
- Детализировал взаимодействие компонентов системы
- Описал последовательность сообщений
- Выявил зависимости между объектами

### Задание 5: ER-диаграмма данных
- Спроектировал модель данных
- Определил сущности и связи
- Нормализовал структуру БД

## Результаты
- ✅ 5+ профессиональных диаграмм (BPMN, UML, ER)
- ✅ Полная документация бизнес-процессов
- ✅ Готовые артефакты для передачи в разработку
- ✅ Выявлены точки оптимизации процессов

## Инструменты
- Draw.io / Lucidchart
- BPMN 2.0
- UML 2.5
- ER-моделирование

## Структура проекта
- `src/bpmn/` — бизнес-процессы
- `src/uml/` — UML диаграммы
- `src/er/` — модель данных
- `src/docs/` — документация
